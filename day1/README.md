# System Information CLI

## Prerequisites

- Node

## Installation

- clone the repo using `git clone`
- move to dist folder
- run `node commandParsing.js`

## Development

- To change the code go to src and see the ts files there.
- To make the cli work with command line arguments instead of taking input from standard input uncomment the specified codes and comment the code of taking input from standard input.

## Build

- In root folder run `npm run build` or `npm run start`

## Test

- To test the code run `npx jest .`
